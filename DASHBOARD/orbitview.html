03 / FRAME DISCIPLINE

Keep orbital coordinates separate from the arm workspace

Orbital coordinates describe the servicer and target in an orbital frame. The robotic arm uses a small local coordinate system only after the mission software has established a capture geometry.

04 / ORBITAL MECHANICS CONTEXT

What this view is meant to answer.

Rendezvous operations depend on orbit determination, relative navigation and controlled guidance. The website keeps those functions separate so the visual scene does not become a substitute for the underlying state record.

ORBIT DETERMINATION

Establish the state

Position and velocity are shown as numerical quantities alongside the spatial display.

RELATIVE NAVIGATION

Work near the target

Close approach is described in terms of relative geometry and motion rather than Earth-centred distance alone.

MISSION DECISION

Carry the state forward

The orbital view informs the mission decision; it does not independently authorize capture or hardware actuation.
