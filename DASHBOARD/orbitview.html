05 · ENGINEERING DISPLAY PRINCIPLES

Professional orbital visualization requires boundaries.

FRAME DISCIPLINE

Earth-centred context

Earth is treated as the central reference body for the visual scene. Relative navigation information is separately identified so orbital coordinates are not confused with the robotic-arm workspace.

PREDICTION DISCIPLINE

No invented trajectory

The current prediction record provides a 60-second horizon and a predicted state. OrbitView therefore marks the prediction point rather than fabricating intermediate orbital samples.

OPERATIONAL DISCIPLINE

Decision remains authoritative

The orbital picture informs mission understanding. It does not independently authorize capture or hardware actuation. Mission decision logic remains upstream of the physical interface.

06 · MODEL BOUNDARY

What OrbitView represents — and what it does not.

REPRESENTED

Earth-centred orbital context, servicer and target positions, reference orbital geometry, target state values, prediction context, relative vector visualization and mission-data provenance.

SIMULATED / MODELED

Object visualization, relative-navigation presentation and prediction-to-display behavior are part of the university project's conceptual simulation environment.

NOT CLAIMED

Flight-qualified navigation, certified collision-avoidance performance, real spacecraft telemetry, operational command authority or agency certification.
