02 · OPERATING LOGIC

One mission, one traceable chain.

The dossier separates observation, state estimation, decision authority and physical action. Each stage declares its principal input, processing function, resulting state and verification focus so that the simulated mission can be inspected as an engineering process rather than as unrelated animations.

MISSION CONTROL PRINCIPLE

OBSERVE → ESTIMATE → AUTHORIZE → ACT → RE-OBSERVE

The control loop is deliberately closed. Measurements are converted into a state estimate, mission logic evaluates constraints and selects an allowed transition, guidance and capture functions act, and the resulting state is observed again before the next cycle.

01
OBSERVE Acquire object, environment and relative-motion measurements.
02
ESTIMATE Maintain a usable relative state and uncertainty representation.
03
AUTHORIZE Evaluate safety, geometry, resources and target validity.
04
ACT Execute the selected guidance, reorientation or capture action.
05
RE-OBSERVE Confirm the resulting state and determine the next transition.
MISSION STATE DISCIPLINE

NO ACTION WITHOUT A VALID STATE

Progression is gated by the information available to the mission manager. Loss of target validity, a safety violation, inadequate relative geometry or insufficient resources routes the sequence to a defined safe state instead of forcing the next action.

H
HOLD Remain safe while additional observations or margin are required.
A
ABORT Terminate proximity activity and return to a defined safe state.
P
PROCEED Enter the applicable capture branch only after the gate is satisfied.
03 · MISSION PHASE MODEL

Three segments. Fifteen controlled stages.

The sequence is grouped by operational purpose. These are simulation-level functional segments, not claims of flight-certified phase boundaries.

FUNCTIONAL DECOMPOSITION
NOT A FLIGHT PROCEDURE
I

DETECT & ASSESS

Build the orbital picture, detect candidates, maintain tracks, estimate state and quantify risk before target authorization.

II

DECIDE & RENDEZVOUS

Select one target, apply decision logic, reorient the spacecraft and execute the simulated rendezvous and controlled approach.

III

CAPTURE & CONTINUE

Configure the mechanism, capture the target, transfer it to storage, verify containment and reset the mission.

05 · DECISION AUTHORITY

Progression is controlled by explicit gates.

The mission manager does not treat every candidate as immediately capturable. Five simulation outcomes keep safety and target validity visible in the operational record.

07 · VERIFICATION & MODEL BOUNDARY

Engineering discipline without overclaiming.

This website presents a conceptual simulation model. It uses systems-engineering traceability patterns, but it does not claim flight qualification, operational certification, regulatory approval or validated orbital performance.

PROJECT MODEL / NOT FLIGHT HARDWARE

Verification focus

Stage-level checks support software and simulation verification such as state-transition testing, algorithm checks, resource accounting and end-to-end scenario testing.

  • Verify every transition against defined mission logic.
  • Route unsafe or invalid conditions to HOLD or ABORT.
  • Maintain one active capture authority.
  • Keep capture, transfer and storage states consistent.
  • Exercise the full sequence using repeatable scenarios.

Model boundary

Project values and mechanisms are simulation assumptions used to make the interface concrete and testable.

  • Surveillance radius and object counts are project configuration values.
  • Spacecraft mass and storage capacity are model parameters.
  • Relative motion and capture behaviour are simulated rather than flight-tested.
  • Graphics are engineering schematics, not manufacturing drawings.
  • Operational decisions remain inside the project mission model.
REFERENCE FRAME: The structure follows common systems-engineering patterns such as ConOps, functional decomposition, state analysis, requirements traceability and verification/validation thinking. It is not a claim of compliance with an external flight standard.
